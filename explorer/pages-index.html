What it is

Native prplMesh, run as containers in one Ubuntu VM: a controller and extenders, a pool of 100 simulated clients, userspace wmediumd as the virtual RF medium, the EasyMesh optimizer, and an interactive room to play scenarios in.

These public pages do not connect to or control a live lab. The explorer is a pinned documentation snapshot; topology placements are illustrative, not live measurements.

Current state

  • A VM built from scratch on 1 October passed the full suite: the expanded acceptance with six devices, the static and browser checks, the four geometry rooms and the catalog of 27 rooms.
  • The wired Agent stays in the controller's model (prplMesh patch 0033), and the controller's memory stays bounded.
